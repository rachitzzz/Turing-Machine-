🧠 Turing Machine Simulator in Java

This repository contains a simple **Turing Machine Simulator** developed in **Java**. It can be used to simulate the behavior of a deterministic Turing machine for educational or research purposes.

📘 About

A Turing machine is a mathematical model of computation that describes an abstract machine capable of performing computations via a tape and a set of states. This Java-based implementation models:
- Infinite tape (bounded by available memory)
- Configurable transition functions
- Multiple states including accepting and rejecting states

🚀 Features

- Configurable input alphabet and tape symbols
- Step-by-step simulation of transitions
- Supports custom transition tables from file or code
- Visual console output of tape movement
- Easily extensible

🛠️ How It Works

1. Define the set of states, input symbols, tape symbols, transition functions, and the accepting/rejecting states.
2. Input a string to the machine.
3. The machine simulates the transitions until it halts (accept/reject).
